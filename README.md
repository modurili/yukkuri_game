# ゆっくり編集地獄

制限時間90秒。何の変哲もない動画素材に **字幕・カット・ズーム・効果音** を付けて、お題どおりの動画に編集するブラウザゲームです。
書き出した動画は視聴者コメント付きで再生され、**編集技術・テンポ・ネタ** の3項目で採点。称号・予想再生数・地獄度が付いた結果画像をXに投稿できます。

- **サーバー不要**：ゲームは `index.html` 1ファイルで完結（CSS・JavaScript・絵・音をすべて内蔵、外部への通信なし）。ダブルクリックで開くだけで遊べます
- ログイン・データベース不要。記録（自己ベスト・図鑑）はブラウザ内に保存
- 素材の映像・キャラクター・効果音・BGMはすべてコードで描画／合成したオリジナル（外部の素材ファイルなし）
- PC・スマートフォン両対応

## 遊び方

1. お題を選ぶ（例：「何の変哲もない公園の映像を、壮大な伏線回収シーンに編集せよ」）
2. 素材（6カット）と制約（例：「字幕は各7文字以内」「効果音は2回まで」「最後は静止画で締める」）を確認
3. 編集画面は動画編集ソフト風（左上プレビュー／下に12レイヤーのタイムライン／右に「アイテム」パネル／下端にセリフ入力欄とステータスバー）。タイムラインのアイテムを選び、次の4項目を編集する（下のセリフ入力欄に書いて Enter でも、選択中のカットに字幕を付けて次のカットへ進めます）
   - **字幕**：用意された字幕 or 自由入力（入力した言葉のジャンルを自動判定）
   - **演出**：ズーム／顔面ドアップ／揺れ／スロー／静止画／モノクロ／逆再生／集中線
   - **効果音**：ドン／爆発／歓声／シュッ／鐘／ざわ…／拍手／チーン／ヒュ〜（カットの見せ場の瞬間に鳴る）
   - **長さ**：1〜3秒、カット（削除）、並べ替え
4. 「書き出す」で、視聴者コメント付きの動画が流れて採点
5. 結果画像を保存・Xにポスト。同じ編集を再生できる「再現リンク」（公開URLがない環境では「再現コード」）で共有できます

残り45秒になるとクライアントから **「追加注文」** が割り込みます（早く書き出せば回避可能）。時間切れになると強制書き出し。

メニュー（ファイル／編集／レイアウト／ツール／ヘルプ、Alt+頭文字で開く）・再生／一時停止・再生位置スライダー・ルーラーのクリック・タイムラインの拡大縮小・音量も使えます。
PCではキーボードでも操作できます：`←` `→` カット選択／`[` `]` 並べ替え／`1`〜`4` タブ切替／`X` カット／`P` 通し再生／`Esc` 一時停止

## お題（初版4種）

| No. | お題 | 制約 | 評価の傾向 |
| --- | --- | --- | --- |
| 1 | 公園 → 伏線回収 | 字幕は各7文字以内／効果音は2回まで／最後は静止画 | 「伏線」字幕 → 後の「回収」字幕の構成を評価。技術重視 |
| 2 | 猫 → ホラー予告編 | モノクロ2カット以上／字幕は3回まで／尺10秒以内 | 恐怖演出と、かわいさとのギャップ |
| 3 | 目玉焼き → スポーツ決勝 | 合計8秒以内／効果音3回以上／「!」付き字幕2つ以上 | 短いカットの畳みかけ。テンポ重視 |
| 4 | カップ麺 → 感動ドキュメンタリー | 効果音1回まで／スロー2カット以上／合計14秒以上 | 長めのカットと余韻。うるさい演出は不利 |

## 採点のしくみ

採点は `src/js/scoring.js` の純粋関数で、同じ編集なら必ず同じ結果になります（再現リンクで点数も再現）。結果画面に加点・減点の理由をすべて表示します。

- **編集技術**：制約の達成／違反、追加注文への対応、衝撃系の効果音を見せ場に合わせたか、見せ場に寄ったか、読み切れない字幕（文字数÷秒数）、字幕過多、締めの演出、締め切りオーバー
- **テンポ**：尺がお題の理想範囲か、カットの長さの緩急、何も起きないカットの間延び、不要カットの削除、演出の量とうるささ、山場の位置と尺、お題ごとの好み（速い／ゆっくり）
- **ネタ**：お題に合ったジャンルの字幕・演出・効果音、「ふつうの映像×お題のジャンル」のギャップ、隠しコンボ（例：鳩×回収系字幕×静止画＝「鳩、黒幕説」）、自作字幕、ツッコミどころ
- 総合点は3項目をお題ごとの重みで合成（S〜Eランク）

正解は1通りではなく、**わざとひどい編集**も遊びとして成立するようにしています。

- **地獄度**（総合点とは別枠）：効果音の連発、激しい演出、字幕の盛りすぎ、制約違反など。高いと「炎上」扱いで予想再生数が伸び、高評価率が下がる
- 極端な編集は「天丼」「顔面ドアップ地獄」「全部盛り」などのコンボや、「効果音の暴力」「字幕過多の罪」などの称号になる
- コンボ図鑑（お題ごと15〜16種、未発見はヒントのみ表示）と称号コレクションはブラウザに保存されます

## 起動・配布・公開（サーバー不要）

`index.html` をブラウザで開くだけです。サーバーの起動もインストールも要りません。

- PC：`index.html` をダブルクリック（またはブラウザにドラッグ＆ドロップ）
- 配布：`index.html` 1ファイルを渡せば、受け取った人もそのまま遊べます
- 公開：`index.html` を静的ホスティング（GitHub Pages、Netlify、Cloudflare Pages、Amazon S3 など）に置くだけ。サーバー側の処理は一切ありません

### 共有のしかた

| 開き方 | 共有方法 |
| --- | --- |
| Webに公開したURLで開いている | Xのポストに「再現リンク」が付き、開くと同じ編集が再生されます |
| ファイルを直接開いている／埋め込み表示など | 「再現コード」をコピーして送ります。相手はタイトル画面の「再現コード・再現リンクで再生する」に貼り付けると同じ編集が再生されます |

どちらもサーバーを使わず、編集内容をリンク／コードの中にまるごと入れています。

- 再現リンクは今開いているページのURLを基準に作ります。ファイルを直接開いて遊んでいても公開先のリンクを付けたい場合は、`src/index.html` の `<meta name="yg-share-url" content="">` に公開URLを書いてビルドしてください。
- Xのリンクカードに画像を出したい場合は、公開後に `og:image` を**絶対URL**で追加してください（初版では未設定。投稿時は保存した結果画像の添付を案内しています）。
- ブラウザの保存領域が使えない環境（一部の埋め込み表示など）でも遊べます。その場合、自己ベストと図鑑は記録されません。

## 開発

ソースは `src/` にあります。`src/index.html` も直接開いて動かせます（開発用。js/・css/ を別ファイルで読み込む）。
変更したら、CSS・JavaScriptを1ファイルにまとめた `index.html` を作り直してください（Node.js のみ、依存パッケージなし）。

```sh
npm run build   # src/ → index.html（単一ファイル）を生成
```

## テスト

```sh
npm test       # index.html が src/ と一致しているか ＋ 採点・コンボ・称号・再現URL・不正な共有データの拒否（node:test）
npm run e2e    # Playwright + Chromium で実際に1プレイ通す（サーバーは使わない）
```

E2Eでは次の3つの開き方で、それぞれ最後まで遊べることを確認します。外部への通信や、`index.html` 以外のファイルの読み込みが1つでもあれば失敗します。

- **Webに公開した状態**（Playwright がリクエストを横取りして `index.html` だけを返す）：タイトル → お題選択 → 編集（字幕・演出・効果音・長さ・カット・自由入力・キーボード）→ 書き出し再生 → 結果 → 画像保存 → Xの投稿画面 → 再現リンクで同じ点数 → 追加注文 → 締め切り、スマホ幅でのタップ操作・横スクロールなし
- **ファイルを直接開いた状態**（`file://`）：1プレイ → 画像保存 → X → 再現コードをコピー → 貼り付けて同じ点数、不正なコードを弾く
- **中身をサンドボックス iframe に流し込んだ状態**（保存領域もURLもない環境）：1プレイ → 再現コードでの共有

スクリーンショットは引数で指定したフォルダ（省略時はOSの一時フォルダ）に保存されます。

## ファイル構成

```
index.html          配布・公開用の完成品（src/ から自動生成。CSS・JSを内蔵した単一ファイル）
src/index.html      画面構成（タイトル／お題選択／ブリーフィング／編集／再生／結果／共有）
src/css/style.css   スタイル（スマホはプレビュー固定、PCは1画面に収まる3カラム）
src/js/data.js      お題・素材・字幕・演出・効果音・コンボ・称号・コメントのデータ
src/js/scoring.js   採点エンジン（DOM非依存）
src/js/codec.js     編集内容 ⇔ 再現コード（検証付き）
src/js/scenes.js    動画素材24カット（Canvasで描くアニメーション）
src/js/render.js    演出・字幕・擬音の描画、キャラクター
src/js/audio.js     効果音・BGM（WebAudioで合成）
src/js/share.js     結果画像（1200×675）とXへの共有、再現リンク／コード
src/js/main.js      画面遷移・編集UI・タイマー・再生・結果
scripts/build.js    src/ を単一ファイルの index.html にまとめる
tests/              採点のユニットテスト、ブラウザE2E
```

## お題を増やすには

`src/js/data.js` の `THEMES` に1件追加します。素材カットの絵は `src/js/scenes.js` の `SHOTS` に関数を足し、`shots[].id` と合わせてください。制約（`constraints`）・追加注文（`order`）・構成ボーナス（`structure`）・コンボ（`specials`）は関数で書けます。最後に `npm run build` を忘れずに。
