# ゆっくり編集地獄

制限時間90秒。何の変哲もない動画素材に **字幕・カット・ズーム・効果音** を付けて、お題どおりの動画に編集するブラウザゲームです。
書き出した動画は視聴者コメント付きで再生され、**編集技術・テンポ・ネタ** の3項目で採点。称号・予想再生数・地獄度が付いた結果画像をXに投稿できます。

- サーバー・ログイン・データベース不要の静的サイト（HTML / CSS / JavaScript のみ、ビルド不要）
- 素材の映像・キャラクター・効果音・BGMはすべてコードで描画／合成したオリジナル（外部の素材ファイルなし）
- PC・スマートフォン両対応

## 遊び方

1. お題を選ぶ（例：「何の変哲もない公園の映像を、壮大な伏線回収シーンに編集せよ」）
2. 素材（6カット）と制約（例：「字幕は各7文字以内」「効果音は2回まで」「最後は静止画で締める」）を確認
3. タイムラインのカットを選び、下の4項目を編集する
   - **字幕**：用意された字幕 or 自由入力（入力した言葉のジャンルを自動判定）
   - **演出**：ズーム／顔面ドアップ／揺れ／スロー／静止画／モノクロ／逆再生／集中線
   - **効果音**：ドン／爆発／歓声／シュッ／鐘／ざわ…／拍手／チーン／ヒュ〜（カットの見せ場の瞬間に鳴る）
   - **長さ**：1〜3秒、カット（削除）、並べ替え
4. 「書き出す」で、視聴者コメント付きの動画が流れて採点
5. 結果画像を保存・Xにポスト。ポストには同じ編集を再生できる「再現リンク」が付きます

残り45秒になるとクライアントから **「追加注文」** が割り込みます（早く書き出せば回避可能）。時間切れになると強制書き出し。

PCではキーボードでも操作できます：`←` `→` カット選択／`[` `]` 並べ替え／`1`〜`4` タブ切替／`X` カット／`P` 通し再生／`Esc` 一時停止

## お題（初版4種）

| No. | お題 | 制約 | 評価の傾向 |
| --- | --- | --- | --- |
| 1 | 公園 → 伏線回収 | 字幕は各7文字以内／効果音は2回まで／最後は静止画 | 「伏線」字幕 → 後の「回収」字幕の構成を評価。技術重視 |
| 2 | 猫 → ホラー予告編 | モノクロ2カット以上／字幕は3回まで／尺10秒以内 | 恐怖演出と、かわいさとのギャップ |
| 3 | 目玉焼き → スポーツ決勝 | 合計8秒以内／効果音3回以上／「!」付き字幕2つ以上 | 短いカットの畳みかけ。テンポ重視 |
| 4 | カップ麺 → 感動ドキュメンタリー | 効果音1回まで／スロー2カット以上／合計14秒以上 | 長めのカットと余韻。うるさい演出は不利 |

## 採点のしくみ

採点は `js/scoring.js` の純粋関数で、同じ編集なら必ず同じ結果になります（再現リンクで点数も再現）。結果画面に加点・減点の理由をすべて表示します。

- **編集技術**：制約の達成／違反、追加注文への対応、衝撃系の効果音を見せ場に合わせたか、見せ場に寄ったか、読み切れない字幕（文字数÷秒数）、字幕過多、締めの演出、締め切りオーバー
- **テンポ**：尺がお題の理想範囲か、カットの長さの緩急、何も起きないカットの間延び、不要カットの削除、演出の量とうるささ、山場の位置と尺、お題ごとの好み（速い／ゆっくり）
- **ネタ**：お題に合ったジャンルの字幕・演出・効果音、「ふつうの映像×お題のジャンル」のギャップ、隠しコンボ（例：鳩×回収系字幕×静止画＝「鳩、黒幕説」）、自作字幕、ツッコミどころ
- 総合点は3項目をお題ごとの重みで合成（S〜Eランク）

正解は1通りではなく、**わざとひどい編集**も遊びとして成立するようにしています。

- **地獄度**（総合点とは別枠）：効果音の連発、激しい演出、字幕の盛りすぎ、制約違反など。高いと「炎上」扱いで予想再生数が伸び、高評価率が下がる
- 極端な編集は「天丼」「顔面ドアップ地獄」「全部盛り」などのコンボや、「効果音の暴力」「字幕過多の罪」などの称号になる
- コンボ図鑑（お題ごと15〜16種、未発見はヒントのみ表示）と称号コレクションはブラウザに保存されます

## 起動方法

ビルドは不要です。

```sh
npm start            # http://localhost:8000/ で起動（Node.js のみ、依存パッケージなし）
# または
python3 -m http.server 8000
```

`index.html` をブラウザで直接開いても遊べます（ただし共有リンクはWebに公開したURLでないと他の人は開けません）。

### 公開（GitHub Pages など）

リポジトリのファイルをそのまま静的ホスティングに置くだけで動きます。GitHub Pages なら Settings → Pages で公開ブランチとルートフォルダを指定してください。

- 共有リンク（`?r=...`）は、今開いているページのURLを基準に作られます。基準URLを固定したい場合は `index.html` の `<meta name="yg-share-url" content="">` に公開URLを書いてください。
- Xのリンクカードに画像を出したい場合は、公開後に `og:image` を**絶対URL**で追加してください（初版では未設定。投稿時は保存した結果画像の添付を案内しています）。

## テスト

```sh
npm test       # 採点・コンボ・称号・URL再現・不正な共有リンクの拒否（node:test）
npm run e2e    # Playwright + Chromium で、PCとスマホ幅で実際に1プレイ通す
```

E2Eでは、タイトル → お題選択 → 編集（字幕・演出・効果音・長さ・カット・自由入力）→ 書き出し再生 → 結果 → 画像保存 → Xの投稿画面 → 再現リンクで同じ点数 → 追加注文 → 締め切り → スマホ幅でのタップ操作・横スクロールなし、までを確認します。スクリーンショットは引数で指定したフォルダ（省略時はOSの一時フォルダ）に保存されます。

## ファイル構成

```
index.html        画面構成（タイトル／お題選択／ブリーフィング／編集／再生／結果／共有リンク）
css/style.css     スタイル（スマホはプレビュー固定、PCは1画面に収まる3カラム）
js/data.js        お題・素材・字幕・演出・効果音・コンボ・称号・コメントのデータ
js/scoring.js     採点エンジン（DOM非依存）
js/codec.js       編集内容 ⇔ 共有URL（検証付き）
js/scenes.js      動画素材24カット（Canvasで描くアニメーション）
js/render.js      演出・字幕・擬音の描画、キャラクター
js/audio.js       効果音・BGM（WebAudioで合成）
js/share.js       結果画像（1200×675）とXへの共有
js/main.js        画面遷移・編集UI・タイマー・再生・結果
scripts/serve.js  依存なしの簡易サーバー
tests/            採点のユニットテスト、ブラウザE2E
```

## お題を増やすには

`js/data.js` の `THEMES` に1件追加します。素材カットの絵は `js/scenes.js` の `SHOTS` に関数を足し、`shots[].id` と合わせてください。制約（`constraints`）・追加注文（`order`）・構成ボーナス（`structure`）・コンボ（`specials`）は関数で書けます。
